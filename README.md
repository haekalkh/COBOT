# 🤖 COBOT – Collaborative Robot for Tomato Picking

COBOT is a computer vision-based collaborative robot project that automates the detection and picking of ripe tomatoes using a robotic arm.

---

## 📌 Features

- 🍅 Ripe tomato detection using computer vision (e.g., YOLO/OpenCV)
- 🦾 Robotic arm control via serial communication
- 📸 Real-time image capture and processing
- 🛠 Modular code structure for further enhancements
